# 논문 함께 읽기

사용자가 **직접 읽고 있는** 논문을 같이 따라가는 세션용 스킬이다.
요약을 대신 써 주는 것이 목적이 아니라, **사용자가 원문을 읽어 낼 수 있게 만드는 것**이 목적이다.

이 볼트의 `CLAUDE.md`가 상위 규칙이다. 충돌하면 `CLAUDE.md`를 따른다.
특히 **읽지 않은 논문에 대해 쓰지 않는다**와 **추측하지 않는다**가 이 스킬 전체에 걸린다.

---

## 0. 환경 준비

컨테이너는 세션마다 초기화되므로 매번 깔아야 한다.

```bash
pip install "markitdown[pdf]" PyMuPDF
```

> **인터프리터 불일치에 주의.** `python3`가 3.11인데 `pip`이 3.13에 설치하는 환경이 있다.
> `import pymupdf`가 실패하면 `pip show -f pymupdf`로 설치 경로를 보고,
> 그 버전의 인터프리터(예: `/usr/local/bin/python3.13`)로 직접 실행한다.
> `head -1 $(which markitdown)`이 어떤 파이썬을 가리키는지 보면 빠르다.

---

## 1. 변환 — 세 겹으로 읽는다

**markitdown 하나로는 부족하다.** 2단 조판 논문에서 왼쪽 줄과 오른쪽 줄을 번갈아 뽑아
문단이 교차하고, 수식은 조각나서 순서가 뒤집힌다. 그래서 세 가지를 같이 쓴다.

| | 도구 | 무엇에 쓰나 |
|---|---|---|
| ① | `markitdown paper.pdf > paper.md` | 사용자가 요청한 형식. 전체 구조 훑기 |
| ② | `scripts/pdf_columns.py` | **본문을 실제로 읽는 용도.** 컬럼 순서 복원 |
| ③ | `scripts/pdf_render.py` | **수식·Figure 확인용.** 페이지를 이미지로 |

```bash
markitdown paper.pdf > paper.md
python3 scripts/pdf_columns.py paper.pdf -o cols.txt
python3 scripts/pdf_render.py paper.pdf --pages 2-5 --half both -o figs/
```

1단 논문이면 `pdf_columns.py --single`.

### 수식은 반드시 이미지로 확인한다

텍스트 추출은 분수의 분자·분모, 적분 기호, 위아래첨자를 **따로 떼어 순서를 뒤집는다.**
식 (4)가 `E_Q[S(τ)] + λD_KL(Q‖P)` → `−λF(S(τ)) = inf` 순으로 나오는 식이다.
이걸 그대로 설명하면 **그럴듯하게 틀린 설명**이 된다.

그래서 어떤 절을 설명하기 전에 **그 절이 있는 단을 렌더링해서 눈으로 본다.**
`zoom`은 3.2 이상이면 충분하다.

### Figure는 적극적으로 보여준다

핵심 그림은 영역을 잘라 사용자에게 보낸다 (`SendUserFile`이 있으면 그걸로).
벡터 그림은 임베드된 래스터가 없으므로 `--crop`으로 영역을 잡아 렌더링하는 수밖에 없다.
그림 번호는 **원문 그대로** (`Fig. 3`) 쓴다.

## 2. 전부 읽고, 구조부터 보고한다

변환이 끝나면 **논문 전체를 읽는다.** 초록만 보고 넘어가지 않는다.

그 다음 사용자에게 **절을 고르게 한다.** 이때 넘기는 것:

- **절 목록** — 번호·제목·쪽수·그 절에 있는 식/그림 번호
- **절마다 필요한 배경지식**과 난이도 (★ 표시)
- **읽기 순서 제안** (아래 3절)
- 변환 품질에 문제가 있었다면 그 사실 (예: "markitdown 출력은 컬럼이 섞여서 따로 추출했다")

사용자가 "순서대로" 하자고 하면 순서대로 간다. 제안은 하되 강요하지 않는다.

---

## 3. 읽기 순서 — 순서대로가 항상 옳지는 않다

논문의 수식에는 세 층이 있다.

```
[층 1] 무엇을 하는가   -> 알고리즘/방법.  반드시 이해해야 함
[층 2] 왜 그게 맞는가   -> 유도의 흐름.   방향만 알면 됨
[층 3] 어떻게 엄밀한가  -> 수학적 정당화. 필요할 때만
```

**층 3이 층 1보다 앞에 배치된 논문이 많다.** 유도를 먼저 깔고 알고리즘을 뒤에 두는 구성이다.
이런 논문은 **알고리즘을 먼저 보고 유도로 돌아가는 쪽**을 제안한다.
답을 알고 나면 유도가 *"그 답이 왜 최적인가"*의 증명으로 읽히지만,
답을 모른 채 증명을 읽으면 아무것도 안 남는다.

판단 기준: **방법 절(Algorithm/Method)이 유도 절 뒤에 있고 유도가 길면** 뒤집기를 제안한다.

제안할 때는 이유를 한 줄로 같이 준다. 그리고 **사용자의 선택을 따른다.**

---

## 4. 식 분류(triage) — 이걸 먼저 준다

사용자가 "이걸 다 이해해야 하냐"고 묻기 **전에** 분류표를 준다.
배경지식이 없는 사람에게 가장 먼저 필요한 건 설명이 아니라 **무엇을 건너뛰어도 되는지**다.

논문의 모든 식을 세 등급으로 나눠 표로 준다.

| 등급 | 뜻 |
|---|---|
| ★★★ | 반드시. 이걸 모르면 구현도 평가도 안 된다 |
| ★ | 모양만. "무슨 꼴인지"만 알면 충분 |
| ☆ | 건너뛰어도 됨. 유도의 중간 단계 |

보통 **전체의 1/3 이하만 ★★★**이고, 가장 어려운 구간이 ☆인 경우가 흔하다. 그걸 명시한다.

**"이해했다"의 기준**도 같이 준다. 수식 암기가 아니라:

1. 구현할 수 있는가
2. 무엇을 바꾸면 무엇이 망가지는지 말할 수 있는가
3. 이 방법이 안 되는 경우를 말할 수 있는가

## 5. 절 설명 — 문장 단위로 쪼갠다

사용자가 절을 지정하면 이 틀로 간다.

### 틀

1. **이 절이 하는 일** — 2~4줄. 절 안의 단계를 먼저 나눠 보여준다
2. **문장별 해설** — 원문을 인용(`>`)하고 바로 아래에 풀이
3. **식이 나오면** 원문 기호 그대로 LaTeX로 옮기고, 기호마다 **뜻과 차원**
4. **기호 총정리 표** — 절이 끝날 때. 기호 / 뜻 / 차원 / 처음 나온 곳
5. **논리 흐름 요약** — 식들이 어떤 순서로 무엇을 증명하는지
6. **🔗 배경지식 자료** (아래 6절)
7. **❓ 짚을 점** (아래 7절)

### 문장별 해설의 원칙

- **원문을 먼저 인용한다.** 사용자가 원문과 대조할 수 있어야 한다
- **전문 용어는 영문 원문 그대로**, 설명만 한국어로
- 한 문장이 여러 일을 하면 **쪼개서** 번호를 붙인다
- **"이게 왜 여기 있는가"**를 말한다. 뒤의 어느 절에서 회수되는지 짚으면 가장 잘 남는다
- 저자가 **가정**을 깐 곳은 명시한다 ("유도가 아니라 가정이다")
- 논문이 스스로 준 정의는 **인용해서 쓴다.** 내가 다시 만들지 않는다

### 숫자와 조건

실험 수치를 옮길 때는 **어디서 굴렸는지를 항상 같이** 말한다.
플랫폼·센서·지형·속도·주행거리 없이 성능 숫자만 옮기면 논문을 잘못 읽은 것이다.

## 6. 배경지식 자료 — 한국어 우선

사용자가 모를 만한 개념은 **학습 자료를 찾아 붙인다.** 가능하면 한국어.

- 검색은 **여러 쿼리를 한 턴에** 보낸다
- **인접 분야에서 찾는다.** 측도론·확률해석(Radon-Nikodym, Girsanov, Feynman-Kac)은
  **금융수학** 쪽에 한국어 자료가 두껍다. 제어·최적화는 로보틱스보다 ML 쪽이 많다
- 자료를 나열하지 말고 **이 논문의 어느 식에 쓰이는지**를 붙여서 순서를 매긴다
- **못 찾으면 못 찾았다고 적는다.** 핵심만 직접 정리해 주고 ⚠️로 표시한다
- 사이트가 차단돼 **본문을 못 열었으면 그 사실을 밝힌다.** 검색 스니펫만 본 것과
  직접 읽은 것은 다르다

**사용자가 이미 아는 것에는 입문 자료를 붙이지 않는다.** `CLAUDE.md`의 배경 정보를 보고
수준을 맞춘다. 모르면 한 번 묻는다.

**자료를 보는 시점도 말해 준다.** 보통은 논문을 먼저 읽고 나서 배경을 메우는 쪽이 빠르다.
동기 없이 선행 지식부터 쌓으면 안 남는다.

## 7. 정확성 — 이 스킬의 생명선

### 논문에 있는 것만 쓴다

- 답할 때 **어디에 있는지**(절·식·Figure 번호)를 같이 밝힌다
- 논문에 없으면 **"논문에 없다"**고 말한다
- 일반 지식으로 메울 때는 **논문 밖 내용임을 명시**한다
- 기억으로 숫자·저자·연도를 채우지 않는다. 인용 논문 [n]을 언급할 때는
  **참고문헌 목록에서 실제 서지를 확인**해서 붙인다

### 논문의 오류를 짚는다

실제 논문에는 오식이 있다. 발견하면 ⚠️로 표시한다. 흔한 것들:

- 첨자 불일치 (루프 변수는 `i`인데 식에는 `j`)
- 알고리즘과 수식의 불일치 (식에 있는 항이 의사코드에 없음)
- 본문의 Figure/절 번호 오기
- 인용 번호가 그 내용의 논문이 아님
- 같은 기호를 두 뜻으로 사용

**단정하지 말고 근거를 댄다.** "식 (32)와 비교하면 Δt가 빠졌다"처럼 비교 대상을 적는다.

### 「❓ 짚을 점」에 넣을 것

절마다 끝에 붙인다. 저자 주장과 실험 근거를 구분하는 자리다.

- 논문이 **명시하지 않은 값** (재현에 필요한데 없는 것)
- 이론과 구현이 **벌어지는 지점**
- 저자가 **검증하지 않은 채 넘어간 것** ("unclear what the effect was")
- 위의 오식들

## 8. 밀도 조절 — 가장 자주 실패하는 곳

**설명을 "전부 이해하는" 수준으로 잡으면 사용자가 막힌다.**
특히 측도론·확률해석이 쏟아지는 절에서 기호 단위로 파고들면 역효과다.

- 4절의 **식 분류를 먼저** 줘서 사용자가 힘을 어디에 쓸지 알게 한다
- 어려운 절에 들어가기 전에 **한 줄로 예고**한다
  ("여기는 대학원 확률론 내용이라 로보틱스 독자 대부분이 넘긴다")
- 사용자가 **"모르겠다", "어렵다", "다 이해해야 하나"**라고 하면
  더 자세히 설명하지 말고 **밀도를 낮추고 순서를 바꾼다.** 이게 올바른 반응이다
- 어떤 절이 끝나면 **다음 선택지를 두세 개 제시**하고 고르게 한다

## 9. 마무리 — 노트와 커밋

질의응답이 끝나고 사용자가 정리를 요청하면 **그 볼트의 `CLAUDE.md` 절차를 따른다.**

> 이 스킬은 여러 볼트에서 쓰인다. **경로·파일명·브랜치는 볼트마다 다르다.**
> 하드코딩하지 말고 `CLAUDE.md`와 실제 디렉터리를 먼저 확인한다.
> (예: attachments 위치가 `Papers/attachments/`인 볼트도, 루트 `attachments/`인 볼트도 있다.
> 용어 파일이 `용어 사전.md`인 곳도 `기호 사전.md`인 곳도 있고, 논문 색인이 없는 볼트도 있다.)

공통으로 하는 일:

- `Papers/<통칭> (제1저자 연도).md` 작성 — `Templates/`의 논문 정리 템플릿을 따른다
- Figure 는 그 볼트의 attachments 규칙대로 저장하고 `![[fig3.png]]` 로 임베드
- 새로 나온 분야 표준 용어는 그 볼트의 용어/기호 사전에 추가
- 질문은 노트의 「❓ 질문」과 `Questions/질문 로그.md` 양쪽에
- 논문 색인 파일이 있으면 후보 목록에서 그 줄을 지운다
- 논문 하나 = 커밋 하나. 푸시는 `CLAUDE.md`가 지정한 브랜치로

**사용자가 요청하기 전에는 노트를 쓰지 않는다.** 읽는 중에는 읽기만 한다.

> [!note] 볼트가 없는 환경에서는
> claude.ai 처럼 git 저장소도 `CLAUDE.md` 도 없는 곳에서는 이 절을 통째로 건너뛴다.
> 정리를 요청받으면 **대화 안에 쓰거나 마크다운 파일 하나로 만들어 건넨다.**
> 나머지 절(변환·읽기 순서·식 분류·문장 단위 설명·배경지식·정확성)은 그대로 적용된다.

## 10. 표기

| | |
|---|---|
| 수식 | **LaTeX.** 인라인 `$\lambda$`, 블록 `$$...$$`. 채팅과 노트 둘 다 |
| 다이어그램 | **기본 ASCII만** (`\| - + > v ^`). 박스 그리기 문자(`┌ ─ ┐ │ └ ┘`)는 깨진다 |
| 전문 용어 | 영문 원문 그대로. 번역하지 않는다 |
| 확인 표시 | ✅ 원문에서 직접 확인 · ⚠️ 근거는 있으나 미검증 · ❓ 확인 못 함 |

기호의 **서체 구분**을 살린다. $\mathbf{F}$(drift)와 $\mathcal{F}$(free energy),
$\mathbb{P}$ / $\mathbb{Q}$ / $\mathbb{Q}^*$ 는 평문으로 쓰면 전부 충돌한다.
