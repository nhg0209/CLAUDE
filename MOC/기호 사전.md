# 기호 사전

RL 논문의 가장 큰 진입 장벽은 **논문마다 같은 개념에 다른 기호를 쓴다**는 점입니다.
새 논문을 읽을 때 이 표와 대조해서, 그 논문만의 표기를 각 노트의 「1. 기호 정리」에 적어둡니다.

---

## 1. 기본 구성 요소 (MDP)

| 기호 | 의미 | 설명 |
|---|---|---|
| $s \in \mathcal{S}$ | 상태 (state) | 대문자 $\mathcal{S}$는 상태 **공간** |
| $a \in \mathcal{A}$ | 행동 (action) | |
| $r$ 또는 $R(s,a)$ | 보상 (reward) | 스칼라 |
| $P(s' \mid s,a)$ | 전이 확률 | 환경의 동역학 |
| $\gamma \in [0,1)$ | 할인율 | 미래 보상의 가치 감쇠 |
| $\rho_0(s)$ | 초기 상태 분포 | |
| $\tau$ | 궤적 (trajectory) | $\tau = (s_0,a_0,r_0,s_1,\dots)$ |

## 2. 정책과 목적함수

| 기호 | 의미 | 설명 |
|---|---|---|
| $\pi(a \mid s)$ | 정책 | 상태에서 행동의 **조건부 분포** |
| $\pi_\theta$ | 파라미터화된 정책 | $\theta$는 신경망 가중치 |
| $\pi_{\theta_{\text{old}}}$ | 업데이트 직전 정책 | on-policy 알고리즘에서 기준점 |
| $J(\theta)$ | 목적함수 | $\mathbb{E}_{\tau \sim \pi_\theta}[R(\tau)]$ — **정책이 만드는 궤적 분포**에 대한 기댓값 |
| $d^\pi(s)$ | 상태 방문 분포 | 정책 $\pi$를 따를 때 $s$에 있을 확률 |

> [!warning] 가장 흔한 혼동
> $J(\theta)$의 기댓값은 **데이터셋이 아니라 정책 자신이 만드는 분포**에 대한 것입니다.
> $\theta$가 바뀌면 기댓값을 재는 분포 자체가 바뀝니다.
> 이것이 지도학습과 RL이 근본적으로 다른 지점이고, policy gradient theorem이 필요한 이유입니다.

## 3. 가치 함수

| 기호 | 의미 | 관계식 |
|---|---|---|
| $G_t$ | 리턴 (누적 보상) | $G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k}$ |
| $V^\pi(s)$ | 상태 가치 | $\mathbb{E}_\pi[G_t \mid s_t=s]$ |
| $Q^\pi(s,a)$ | 행동 가치 | $\mathbb{E}_\pi[G_t \mid s_t=s, a_t=a]$ |
| $A^\pi(s,a)$ | 이점 (advantage) | $Q^\pi(s,a) - V^\pi(s)$ |
| $\delta_t$ | TD 오차 | $r_t + \gamma V(s_{t+1}) - V(s_t)$ |

> [!note] 왜 Advantage를 쓰는가
> $A = Q - V$는 "**평균보다 얼마나 나은가**"입니다.
> $Q$를 그대로 쓰면 모든 행동의 값이 다 크거나 다 작아서 그래디언트 분산이 커집니다.
> $V$를 빼는 것(baseline)은 **기댓값을 바꾸지 않으면서 분산만 줄입니다.**

## 4. ⚠️ 논문마다 뜻이 달라지는 기호

여기가 진짜 함정입니다.

| 기호 | 문맥 A | 문맥 B |
|---|---|---|
| $\epsilon$ | **DQN**: $\epsilon$-greedy 탐험률 | **PPO**: clipping 범위 (보통 0.2) |
| $\alpha$ | 대부분: 학습률 | **SAC**: 엔트로피 온도(temperature) |
| $\beta$ | **PPO(KL 버전)**: KL 페널티 계수 | **PER**: importance sampling 지수 |
| $\lambda$ | **GAE**: bias–variance 조절 | **TD($\lambda$)**: eligibility trace 감쇠 |
| $\rho$ | 상태 분포 $\rho_0$ | importance sampling 비율 |
| $R$ | 보상 함수 $R(s,a)$ | 리턴 $R(\tau)$ (= $G$) |
| $\tau$ | 궤적 | **SAC 일부 문헌**: 온도 파라미터 |

> [!tip]
> $\lambda$의 두 용법은 사실 **같은 뿌리**입니다. 둘 다 "몇 스텝 앞까지 실제 보상을 믿을 것인가"를 조절합니다.
> $\lambda=0$이면 1-step TD(편향 높음/분산 낮음), $\lambda=1$이면 Monte Carlo(편향 없음/분산 높음).

## 5. 자주 나오는 연산자

| 기호 | 의미 |
|---|---|
| $D_{\mathrm{KL}}(p \parallel q)$ | KL 발산 — **비대칭**. 순서가 중요합니다 |
| $\mathcal{H}(\pi)$ | 엔트로피 — 정책의 무작위성 |
| $\mathbb{E}_{x \sim p}[\cdot]$ | 분포 $p$에서 뽑은 $x$에 대한 기댓값 |
| $\nabla_\theta$ | $\theta$에 대한 그래디언트 |
| $r_t(\theta)$ | **PPO**: $\dfrac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)}$ 확률비 |
| $\mathcal{D}$ | 데이터셋 / replay buffer |
| $\text{clip}(x, l, u)$ | $x$를 $[l,u]$로 자르기 |

## 6. 구현할 때의 shape 관례

| 표기 | 일반적 텐서 shape |
|---|---|
| 배치 관측 | `(B, obs_dim)` 또는 `(B, C, H, W)` |
| 정책 출력 (이산) | `(B, n_actions)` — logits |
| 정책 출력 (연속) | `(B, act_dim)` × 2 — mean, log_std |
| 가치 출력 | `(B, 1)` 또는 `(B,)` |
| 롤아웃 버퍼 | `(T, N, ...)` — T=스텝, N=병렬 환경 |

> [!warning] 실수 1순위
> `(T, N, ...)`을 `(T*N, ...)`으로 flatten할 때 **순서**를 틀리면
> GAE 계산에서 서로 다른 환경의 궤적이 섞입니다. 학습이 조용히 망가집니다.
