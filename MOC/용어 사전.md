# 용어 사전

오프로드 문헌은 **로보틱스 · terramechanics(토양역학) · RL** 세 전통이 섞여 있어서
같은 기호가 세 가지 뜻으로 쓰입니다. 새 논문을 읽을 때 이 표와 대조하고,
그 논문만의 표기를 각 노트의 「1. 문제 정의」 앞에 적어둡니다.

> [!warning] RL 배경이 있으면 특히 §5를 먼저 보세요
> $\alpha$, $\lambda$, $\tau$, $\mu$, $\beta$ — **RL에서 쓰던 뜻과 전부 충돌합니다.**

---

## 1. Traversability

| 용어 | 뜻 |
|---|---|
| **traversability** | 어떤 지형을 통과할 수 있는 정도. **이진이 아니라 연속적인 비용**이고, **플랫폼·속도에 종속** |
| **navigability** | 거의 동의어. [[GANav (Guan 2021)]]처럼 semantic class를 등급으로 묶을 때 주로 씀 |
| **geometric obstacle** | 형상만으로 판정되는 장애물 (바위, 절벽) |
| **non-geometric obstacle** | **형상은 장애물인데 실제로는 통과 가능**하거나 그 반대 (높은 풀, 얕은 물, 마른 덤불). 오프로드의 핵심 난제 |
| **costmap** | 셀마다 통과 비용. planner가 직접 먹는 형태 |
| **speedmap** | 셀마다 **낼 수 있는 최대 속도**. cost보다 물리적 의미가 뚜렷해 최근 선호 |
| **competence** | "이 플랫폼이 이 지형에서 이 속도를 낼 수 있는가". [[CAHSOR (2024)]] |

## 2. 차량–지형 상호작용 (terramechanics)

| 기호 | 의미 | 비고 |
|---|---|---|
| $i$ | **slip ratio** — $i = 1 - v/(\omega r)$ | 바퀴가 도는 만큼 안 나갈 때 양수. 오프로드에서 **상시** 0이 아님 |
| $\alpha$ | **slip angle** — 바퀴 진행방향과 바퀴 평면의 각 | ⚠️ RL의 entropy 온도, CVaR의 신뢰수준과 충돌 |
| $\beta$ | **차체 slip angle** (sideslip) | RL 볼트 「프로젝트 스택」 §8-3의 `state[6]`이 이것 |
| $z$ | **sinkage** — 바퀴가 지면에 가라앉는 깊이 | 강체 접촉에는 없는 개념. 변형 지형에서만 |
| $\mu$ | **마찰계수** | ⚠️ 통계의 평균 $\mu$ 와 충돌 |
| **drawbar pull** | 견인력에서 주행저항을 뺀 순 추력 | terramechanics의 표준 성능 지표 |
| **traction** | 실제로 지면에 전달되는 구동력. 논문에 따라 $[0,1]$ 계수로 정규화 | [[WayFAST (Gasparino 2022)]]가 이걸 **라벨**로 씀 |
| **bulldozing** | 바퀴 앞에 흙이 밀려 쌓이며 생기는 저항 | |

### 반경험 모델 (semi-empirical)

| 모델 | 식 | 무엇을 준다 |
|---|---|---|
| **Bekker–Wong** | $p = \left(\dfrac{k_c}{b} + k_\phi\right) z^{\,n}$ | 압력–침하 관계. $b$ = 접지폭, $n$ = 침하 지수 |
| **Janosi–Hanamoto** | $\tau = (c + \sigma\tan\phi)\left(1 - e^{-j/K}\right)$ | 전단응력–전단변위 관계. $c$ = 점착력, $\phi$ = 내부마찰각, $K$ = 전단변형계수 |

> [!note] 이 두 식이 SCM의 뿌리다
> [[Project Chrono]]의 **SCM(Soil Contact Model)** 은 위 두 반경험 모델의 일반화로,
> 실시간에 돌릴 수 있게 만든 것입니다. 반대편 극단이 **DEM**(입자 하나하나를 시뮬)이고 훨씬 무겁습니다.
> → [[Terramechanics]]

## 3. 표현 (representation)

| 용어 | 뜻 |
|---|---|
| **proprioceptive** | 내부 감각 — IMU, 휠 엔코더, 모터 전류, 서스펜션. **지나가 봐야 얻어진다** |
| **exteroceptive** | 외부 감각 — 카메라, LiDAR. **미리 얻어진다** |
| **BEV (Bird's Eye View)** | 위에서 내려다본 격자 표현. 오프로드 인지의 사실상 표준 출력 형태 |
| **elevation map / 2.5D** | 셀마다 높이 하나. 동굴·나뭇가지 아래를 표현 못 하는 한계 |
| **implicit neural representation** | 격자 대신 좌표→값 신경망. [[Implicit Neural Traversability (2025)]] |
| **hindsight labeling** | 지나간 뒤 실제 결과로 과거 관측에 라벨을 붙이는 것. **A-2 계열의 엔진** |

## 4. 불확실성 · 위험

| 용어 | 뜻 |
|---|---|
| **aleatoric uncertainty** | 데이터 자체의 무작위성. 데이터를 더 모아도 안 줄어듦 (같은 흙도 매번 다르게 미끄러짐) |
| **epistemic uncertainty** | 모델이 몰라서 생기는 불확실성. **가 본 적 없는 지형** — 데이터를 모으면 줄어듦 |
| **VaR$_\alpha$** | Value-at-Risk. 비용 분포의 $\alpha$ 분위수 |
| **CVaR$_\alpha$** | Conditional VaR. **VaR 이상 구간의 조건부 기댓값** = "나쁜 경우들의 평균" |
| **evidential deep learning** | 예측과 함께 그 예측의 증거량을 내는 방식. [[EVORA (Cai 2023)]] |
| **OOD detection** | 분포 밖 입력 검출. [[Probabilistic Traversability (Cai 2022)]]는 latent density로 함 |

> [!tip] 왜 CVaR인가 — 한 줄
> 오프로드 실패는 "조금 느려짐"이 아니라 **"전복해서 끝"** 이다.
> 비용 분포의 꼬리가 두껍고 비대칭이라 **기댓값이 위험을 과소평가**한다.
> → [[CVaR]]

## 5. ⚠️ 기호 충돌표 — 여기가 진짜 함정

RL 볼트 「기호 사전」 §4와 **이어서 보세요.** 같은 기호가 도메인을 넘으면 뜻이 또 바뀝니다.

| 기호 | RL에서 | 오프로드에서 | 또 다른 뜻 |
|---|---|---|---|
| $\alpha$ | **SAC**: entropy 온도 | **차량**: slip angle | **CVaR**: 신뢰수준 $\alpha$ |
| $\lambda$ | **GAE**: bias–variance 조절 | **MPPI**: inverse temperature | reward 항 가중치 |
| $\tau$ | **soft update** 계수 / 궤적 | **전단응력** (Janosi–Hanamoto) | |
| $\mu$ | (드묾) | **마찰계수** | 통계의 **평균** |
| $\beta$ | **PER**: IS 지수 | **차체 sideslip angle** | |
| $c$ | — | **토양 점착력** (cohesion) | **cost** |
| $\phi$ | — | **내부마찰각** | heading/yaw ($\psi$ 와 혼용됨) |
| $z$ | — | **sinkage** | 높이 좌표 / latent 변수 |
| $S$ | 상태공간 $\mathcal{S}$ | — | **MPPI**: 궤적 cost-to-go $S(\tau)$ |
| $i$ | 인덱스 | **slip ratio** | |
| $K$ | — | **전단변형계수** | 제어 게인 |

> [!danger] 실수 1순위
> **$\alpha$ 를 논문 하나 안에서도 두 뜻으로 쓰는 논문이 있다.**
> risk-aware RL 논문(CVaR + entropy)이 특히 그렇다.
> 노트를 쓸 때 **그 논문의 $\alpha$ 가 무엇인지 맨 앞에 못 박아두세요.**

## 6. 학습 방식

| 용어 | 뜻 |
|---|---|
| **self-supervision** | 라벨을 사람이 아니라 **데이터 자체에서** 만듦. 오프로드에서는 대개 = 주행 결과 |
| **privileged learning** | 시뮬/후처리에서만 얻는 정보를 학습에 활용. 배포 시엔 없음 |
| **teacher–student** | 특권 정보를 보는 teacher policy → 실차 관측만 보는 student로 증류. [[Learning Quadrupedal Locomotion (Lee 2020)]] |
| **asymmetric actor-critic** | critic만 특권 관측. **teacher-student와 같은 문제의 다른 답** (→ RL 볼트 「RL 지도」) |
| **domain randomization** | 시뮬 파라미터를 흔들어 실차 격차 흡수. 오프로드에서는 **지형 자체**도 randomization 대상 |
| **automatic curriculum** | 성능 지표로 난이도를 자동 조절. [[VertiSelector (2024)]] |
| **zero-shot transfer** | 실차에서 추가 학습 없이 바로 동작 |
