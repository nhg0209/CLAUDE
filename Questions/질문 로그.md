# 질문 로그

논문을 읽으며 던진 질문과 답을 시간순으로 쌓습니다.
각 논문 노트의 「❓ 질문」 절과 중복되지만, **여기는 개념별로 다시 찾기 위한 색인**입니다.

> [!important] 여기 들어가는 것
> **논문 내용에 대한 질문만.**
> 볼트 운영·git·플러그인 설정 같은 것은 적지 않습니다.

> [!tip] 이 파일의 가치
> 같은 질문을 6개월 뒤에 또 던지게 됩니다. 그게 정상입니다.
> 그때 "이건 BADGR 읽을 때 물어봤던 것"이라고 연결되면, 그 개념이 **어디서 반복해서 걸리는지**가 보입니다.
> 반복해서 걸리는 개념이 곧 아직 안 잡힌 개념입니다.

## 시간순 로그

### 2026-09-09 · [[WVN (Mattamala 2024)]]

논문을 읽은 뒤 12개 질문. **답 전문은 해당 논문 노트의 「❓ 질문」 절**에 파이프라인 순서(A~F)로
묶여 있다. 여기에는 무엇을 물었고 어디서 답이 나왔는지만 남긴다.

| 묶음 | 다룬 것 | 근거 절 |
|---|---|---|
| **A. 라벨은 어디서 오는가** | traction의 플랫폼 의존성, class 단계 제거 | §3.3.1, §2.2, §2.3, §5.1 |
| **B. 라벨이 이미지에 붙는 경로** | Supervision/Mission Graph, 과거 이미지로의 재투영, 노드 생성 vs 라벨 갱신 | §3.4.1~§3.4.3 |
| **C. Feature와 embedding** | $\mathbf{f}_n$ 의 생성 경로, RGB만 쓴다는 점, 채널의 의미 | Table 1, §3.2.2, §3.2.3, §5.1, Fig. 2 |
| **D. 추론 방식** | segment-wise/pixel-wise가 각각 어디에 쓰였나, 비교가 정성뿐이라는 점 | §3.2.4, §5.2.3, §5.2.5, §5.3.1 |
| **E. Confidence** | 식 (3)의 복원 대상, $(1-c)$ 가중의 세 경우, 두 가지 사용처 | §3.5.1~§3.5.3, §5.2.4 |
| **F. 논문의 위치** | ablation의 소재, [10]과의 관계, 기여 5개 | §1, §3.5.3, §5.3 |

- §5.3.1 첫 문단이 *"Fig. 12"* 로 시작하지만 문맥과 캡션상 **Fig. 11**
